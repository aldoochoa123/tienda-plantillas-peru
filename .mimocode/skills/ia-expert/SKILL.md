### 2. Flujos de IA para la tienda

#### Flujo 1: Crear plantilla nueva con IA
```
1. ChatGPT: "Dame 10 ideas de plantillas Excel para [rubro] en Peru"
2. ChatGPT: "Crea la estructura de datos para [plantilla elegida]"
3. Python + openpyxl: Generar el .xlsx con formulas
4. DALL-E: Crear thumbnail atractivo
5. ChatGPT: Escribir descripcion para el catalogo
6. Publicar en la tienda
```

#### Flujo 2: Crear contenido para redes
```
1. ChatGPT: "Genera 7 posts para esta semana sobre plantillas Excel"
2. Canva AI: Crear graficos para cada post
3. CapCut: Editar video corto de demo
4. Programar en Meta Business Suite
```

#### Flujo 3: Responder clientes por WhatsApp
```
1. Cliente escribe consulta
2. Copiar a ChatGPT: "Responde como vendedor peruano amigable: [consulta]"
3. Adaptar respuesta (agregar emoji, tono local)
4. Enviar por WhatsApp
```

#### Flujo 4: Crear un curso con IA
```
1. ChatGPT: "Diseña el outline de un curso de [tema] para Peru"
2. ChatGPT: "Escribe el guion del modulo 1"
3. HeyGen/Synthesia: Generar video con avatar (opcional)
4. Canva: Crear slides y materiales
5. Subir a Hotmart
```

### 3. Prompts efectivos (templates)

**Para copy de ventas:**
```
Eres un copywriter experto en ventas online en Peru. 
Escribe un texto de venta para [PRODUCTO] que cuesta S/[PRECIO].
Publico: [DESCRIPCION DEL CLIENTE IDEAL]
Incluye: gancho, problema, solucion, prueba social, CTA
Tono: [casual/profesional/urgente]
Maximo: [NUMERO] palabras
```

**Para descripciones de producto:**
```
Escribe una descripcion atractiva para [PRODUCTO] dirigida a 
emprendedores peruanos. Incluye:
- Beneficio principal (no caracteristica)
- 3 puntos clave
- Precio en soles
- CTA con WhatsApp
Maximo 150 palabras.
```

**Para ideas de contenido:**
```
Genera 10 ideas de contenido para [REDES/PLATAFORMA] sobre 
[TEMA] para una tienda de productos digitales en Peru.
Formato: titulo + gancho + tipo de contenido (reel/post/story)
```

### 4. IA para analisis de negocio

**Analisis de competencia:**
- Usar ChatGPT para resumir competidores encontrados en Google
- Pedir comparacion de precios, productos, posicionamiento

**Segmentacion de mercado:**
- Pedir a ChatGPT que segmente el mercado peruano por rubro
- Identificar nichos sin atender

**Pronostico de ventas:**
- Dar datos historiales a ChatGPT
- Pedir proyeccion y recomendaciones

### 5. Limites de la IA (lo que NO puede hacer)

- **No reemplaza la relacion humana** — WhatsApp sigue siendo el cierre
- **No genera contenido perfecto** — siempre revisar y adaptar
- **No conoce tu mercado local** — darle contexto peruano siempre
- **No sustituye estrategia** — IA ejecuta, tu decides la direccion
- **Cuidado con datos sensibles** — no pasar datos de clientes a IA publica
