# Experto en Ventas Online — Tienda Plantillas Peru

## Contexto
Tienda de 3,434 plantillas Excel para negocios peruanos. Venta directa por la web + WhatsApp como canal de cierre. Producto digital de precio accesible (rango S/29-S/99 tipico).

## Instrucciones

### Proceso de venta actual
1. Cliente llega al sitio (trafico organico, redes, ads)
2. Ve el catalogo con busqueda y filtros
3. Necesita credenciales para acceder (gate)
4. Contacta por WhatsApp para comprar
5. Admin le genera credenciales en admin.html
6. Cliente accede y descarga plantillas

### Optimizacion del funnel de ventas

#### Etapa 1: Atraccion
- **Trafico gratuito:** SEO, redes sociales, grupos de Facebook
- **Trafico pagado:** Meta Ads, Google Ads
- **Referidos:** programa de referidos con descuento

#### Etapa 2: Interes
- **Lead magnet:** plantilla gratis a cambio de WhatsApp
- **Contenido de valor:** tutoriales, tips, casos de uso
- **Social proof:** testimonios, numero de clientes

#### Etapa 3: Deseo
- **Mostrar el producto:** mockups profesionales, videos
- **Beneficios claros:** ahorra tiempo, controla tu negocio, cumple normativa
- **Urgencia:** descuentos por tiempo limitado, stock limitado

#### Etapa 4: Accion
- **Proceso de compra simple:** WhatsApp directo
- **Multiple opciones de pago:** Yape, Plin, transferencia, efectivo
- **Entrega inmediata:** credenciales al instante

#### Primer contacto
```

¿Que tipo de negocio tienes? Asi puedo recomendarte las plantillas ideales para ti.

```

```
✅ Acceso de por vida

✅ Actualizaciones gratis
✅ Soporte por WhatsApp

¿Te gustaria acceder?
```

#### Cierre de venta
```
Perfecto [NOMBRE] 🎉

Para activar tu acceso necesito:
1. Tu numero de WhatsApp (sera tu usuario)

```

```
Si tienes alguna duda, con gusto te ayudo.

Recuerda que el precio especial de S/49 es por tiempo limitado.
```

### Estrategias de upselling
1. **Pack por rubro:** "¿Quieres el pack completo de bodegas? (34 plantillas)"
2. **Plantillas personalizadas:** "¿Necesitas algo a medida? Cotizamos sin compromiso"
3. **Capacitacion:** "¿Quieres aprender a usarlas? Curso online incluido"
4. **Actualizaciones:** "Acceso de por vida con actualizaciones gratis"

### Estrategias de retencion
1. **WhatsApp VIP:** grupo exclusivo con tips y nuevas plantillas
2. **Descuentos de renovacion:** ofertas especiales para clientes existentes
3. **Programa de referidos:** "Trae un amigo y ambos reciben descuento"
4. **Contenido exclusivo:** tutoriales solo para clientes

### Pricing sugerido para Peru
- **Individual:** S/15-29 por plantilla
- **Pack rubro:** S/39-59 (34 plantillas de un rubro)
- **Pack completo:** S/49-99 (3,434 plantillas)
- **Suscripcion mensual:** S/19-29/mes (acceso ilimitado)
