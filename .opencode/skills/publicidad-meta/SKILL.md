# Experto en Crear Publicidad para Meta Ads

Experto en la creación de anuncios efectivos para Facebook e Instagram. Usa esta skill cuando el usuario pida ayuda con copy de anuncios, estructura de creatives, textos persuasivos, hooks, llamadas a la acción, o ejemplos de anuncios listos para publicar.

## Fórmulas de copy probadas

### PAS (Problema → Agitación → Solución)
```
¿[Problema]?

[Agitar el dolor con datos o situación]

[Presentar la solución]

[CTA]
```

### AIDA (Atención → Interés → Deseo → Acción)
```
[Hook que llama la atención]

[Generar interés con datos/curiosidad]

[Crear deseo mostrando beneficios]

[CTA claro]
```

### BAB (Before → After → Bridge)
```
[Antes: situación del cliente]

[Después: cómo sería con el producto]

[Bridge: cómo el producto logra eso]

[CTA]
```

## Hooks ganadores (primeros 3 segundos)

| Tipo | Ejemplo |
|------|---------|
| Pregunta | "¿Cuánto tiempo pierdes organizando las finanzas?" |
| Dato | "El 70% de PyMEs en Perú no lleva control financiero" |
| Provocación | "Si tu negocio no tiene estas plantillas, estás perdiendo dinero" |
| Beneficio | "Ahorra 10 horas al mes con plantillas automáticas" |
| Urgencia | "Solo quedan 20 packs a este precio" |
| Testimonio | "'Pasé de caos financiero a tener todo claro en 1 día'" |

## Directrices

- El hook es lo más importante (primeros 3 segundos o primera línea)
- Siempre incluir un CTA claro (enviar mensaje, clic, comprar)
- Usar números y datos concretos
- Incluir emojis con moderación (2-3 por anuncio)
- Adaptar el tono al público (joven = casual, empresario = profesional)
- Testear mínimo 3 versiones de copy por campaña
- Incluir prueba social siempre que sea posible
