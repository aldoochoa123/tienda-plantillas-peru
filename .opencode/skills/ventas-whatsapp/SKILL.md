# Ventas por WhatsApp

Experto en ventas y atención al cliente por WhatsApp Business. Usa esta skill cuando el usuario pida ayuda con respuestas a clientes, scripts de venta, automatización de mensajes, objeciones, cierre de ventas, o gestión de conversaciones por WhatsApp.

## Contexto del proyecto

Tienda de plantillas Excel para negocios peruanos. Venta directa por WhatsApp después de contacto desde Facebook Ads.

## Flujo de venta actual

1. Cliente ve anuncio en Facebook → clic en WhatsApp
2. Bot o vendedor responde dudas
3. Se concreta la venta
4. Se envían credenciales (usuario/contraseña) + link de acceso
5. Cliente descarga las plantillas

## Scripts de venta

### Primer contacto (cuando llega del anuncio)
```
Hola [nombre] 👋 ¡Gracias por escribirnos!

¿Ya viste nuestro pack de 3,434 plantillas Excel profesionales para negocios en Perú?

Tenemos plantillas con IGV, AFP, RUC, Yape/Plin y todo lo que necesitas para tu negocio.

¿Me cuentas qué tipo de negocio tienes? Así te muestro las plantillas que más te van a servir 🎯
```

### Cuando preguntan el precio
```
El pack completo de 3,434 plantillas tiene un precio de S/ [precio].

Incluye:
✅ Dashboard financiero
✅ Control de ventas e inventario
✅ Planilla con AFP/ONP
✅ Flujo de caja
✅ Control tributario (IGV, PDT 621)
✅ Y mucho más...

¿Te gustaría que te envíe el acceso? 💳
```

### Cuando hay objeción de precio
```
Entiendo tu consulta. Piénsalo así:

Un contador te cobra S/ 200-500 al mes. Con estas plantillas tú solo manejas todo por una fracción del precio.

Además, las plantillas tienen fórmulas automáticas — solo ingresas tus datos y todo se calcula solo.

¿Quieres que te muestre una demostración? 📊
```

### Cierre de venta
```
¡Perfecto! 🎉

Tu acceso está listo:
👤 Usuario: [número]
🔐 Contraseña: [clave]
🔗 Entra aquí: https://tienda-plantillas-peru.vercel.app

Descarga todas las plantillas que necesites, las veces que quieras.

Si tienes alguna duda, escríbeme aquí mismo. ¡Éxito con tu negocio! 💪
```

### Post-venta (después de 24-48h)
```
Hola [nombre] 👋 ¿Qué tal? ¿Ya pudiste descargar tus plantillas?

Si necesitas ayuda con alguna fórmula o no encuentras una plantilla, dime y te ayudo.

¡Que te vaya bien con tu negocio! 🚀
```

## Manejo de objeciones comunes

| Objeción | Respuesta |
|----------|-----------|
| "Es muy caro" | Comparar con costo de contador o software |
| "No sé usar Excel" | Ofrecer guía básica, las plantillas ya tienen fórmulas |
| "¿Es seguro?" | Mostrar testimonios, garantía de satisfacción |
| "Lo pienso" | Crear urgencia (oferta limitada, bonos) |
| "¿Tienen para mi rubro?" | Confirmar que sí, mostrar categorías relevantes |

## Directrices

- Responder en menos de 5 minutos (ideal)
- Usar emojis con moderación (profesional pero cercano)
- Nunca presionar, siempre guiar
- Personalizar según el rubro del cliente
- Siempre cerrar con una pregunta o llamada a la acción
