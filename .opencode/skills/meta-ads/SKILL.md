# Experto en Meta Ads

Experto en publicidad pagada en Facebook e Instagram (Meta Ads). Usa esta skill cuando el usuario pida ayuda con campañas, presupuestos, segmentación, optimización, remarketing, o cualquier aspecto de publicidad en Meta.

## Estructura de cuenta

```
Cuenta publicitaria
├── Campaña (objetivo)
│   ├── Conjunto de anuncios (audiencia + presupuesto)
│   │   ├── Anuncio 1 (creative A)
│   │   ├── Anuncio 2 (creative B)
│   │   └── Anuncio 3 (creative C)
│   └── Conjunto de anuncios 2 (audiencia B)
│       └── ...
└── Campaña 2
    └── ...
```

## Campañas recomendadas para la tienda

### Fase 1: Awareness (conocimiento)
- **Objetivo:** Alcance o reproducciones de video
- **Audiencia:** Intereses en Excel, contabilidad, PyMEs, emprendimiento
- **Presupuesto:** S/ 10-20/día
- **Creative:** Video corto mostrando las plantillas

### Fase 2: Consideración (tráfico)
- **Objetivo:** Tráfico al WhatsApp
- **Audiencia:** Lookalike de compradores + intereses relevantes
- **Presupuesto:** S/ 15-30/día
- **Creative:** Carrusel de plantillas + CTA a WhatsApp

### Fase 3: Conversión (ventas)
- **Objetivo:** Mensajes de WhatsApp
- **Audiencia:** Retargeting de visitantes + lookalike
- **Presupuesto:** S/ 20-50/día
- **Creative:** Testimonio + oferta + urgencia

### Fase 4: Retención (remarketing)
- **Objetivo:** Tráfico
- **Audiencia:** Compradores anteriores
- **Presupuesto:** S/ 5-10/día
- **Creative:** Nuevas plantillas, upsell

## Segmentación para Perú

### Audiencia fría (prospecting)
```
Ubicación: Perú (ciudades principales)
Edad: 25-55
Idioma: Español
Intereses:
  - Contabilidad
  - Microsoft Excel
  - PyMEs / Pequeñas empresas
  - Emprendimiento
  - Negocios
  - Facturación electrónica
  - Administración de empresas
Comportamiento:
  - Administradores de páginas de Facebook
  - Pequeños empresarios
```

### Audiencia caliente (retargeting)
```
Visitantes del sitio web (últimos 30 días)
Personas que enviaron mensaje pero no compraron
Personas que interactuaron con anuncios (últimos 14 días)
```

### Lookalike (similar)
```
1% Lookalike de compradores
1% Lookalike de visitantes del sitio
2-5% Lookalike de engagement
```

## Presupuesto recomendado

| Fase | Presupuesto diario | Duración | Total |
|------|-------------------|----------|-------|
| Testing | S/ 10-20 | 7 días | S/ 70-140 |
| Escalar winners | S/ 30-50 | 14 días | S/ 420-700 |
| Escala completa | S/ 50-100+ | Continuo | — |

## Métricas clave

| Métrica | Objetivo | Fórmula |
|---------|----------|---------|
| CTR | > 1.5% | Clics / Impresiones |
| CPC | < S/ 0.50 | Gasto / Clics |
| CPM | < S/ 15 | (Gasto / Impresiones) × 1000 |
| ROAS | > 3x | Revenue / Gasto |
| CPA | < S/ 15 | Gasto / Conversiones |
| Frecuencia | < 3 | Impresiones / Alcance |

## Optimización

- Esperar mínimo 50 conversiones antes de optimizar
- No cambiar nada los primeros 3 días (fase de aprendizaje)
- Apagar anuncios con CTR < 0.5% después de 3 días
- Escalar ganadores aumentando 20% del presupuesto cada 2-3 días
- Rotar creatives cada 2-3 semanas (fatiga de anuncios)

## Estructura de anuncio ganador

```
Gancho (primeros 3 segundos) → Problema → Solución → Prueba → CTA

Ejemplo:
"¿Pierdes horas organizando las finanzas de tu negocio?"
"Con nuestras plantillas Excel profesionales..."
"Más de 500 negocios en Perú ya las usan"
"Haz clic en el botón y escríbenos por WhatsApp"
```

## Directrices

- Siempre testear mínimo 3 creatives por conjunto
- Usar formato vertical (9:16) para Stories/Reels
- Incluir CTA claro en cada anuncio
- No editar anuncios en fase de aprendizaje
- Revisar métricas diariamente
- Pausar lo que no funciona, escalar lo que sí
