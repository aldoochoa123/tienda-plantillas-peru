# 📦 Tienda Plantillas Excel Perú

**3,434 plantillas Excel profesionales** para negocios en Perú.

## 📋 Contenido

- **101 rubros peruanos**: Bodega, Pollería, Farmacia, Taller, etc.
- **34 tipos de plantilla**: Dashboard, Inventario, Planilla, CTS, etc.
- **9 categorías**: Alimentos, Comercio, Servicios, Salud, etc.

## 🇵🇪 Datos locales

- IGV 18% calculado automáticamente
- AFP (Integra/Prima/Profuturo) y ONP
- EsSalud 9%, RMV S/ 1,130
- RUC de clientes y proveedores
- Boleta / Factura electrónica
- Yape / Plin / Transferencia
- PDT 621 y control tributario

## 🚀 Uso

### Ver catálogo
```bash
npx serve . -l 3000
# Abrir http://localhost:3000
```

### Estructura
```
├── index.html                    # Catálogo interactivo
├── pack-1000-plantillas-peru.zip # Pack completo (28 MB)
├── CATALOGO.xlsx                 # Catálogo en Excel
└── plantillas/                   # 3,434 archivos .xlsx
    ├── Alimentos y Bebidas/
    ├── Comercio y Retail/
    ├── Servicios/
    └── ... (9 categorías)
```
